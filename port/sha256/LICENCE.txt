Tools/SHA256
============

Tools/SHA256 is the small AmigaOS command the Installer runs to check a
SHA-256. It was written for these ports by the AmiCradle Team from the
SHA-256 definition in FIPS 180-4; it contains no third-party code. Its
source is port/sha256/sha256.c in the port's repository, and
scripts/build-sha256.sh builds it with GFOpenAmigaGCC 16.2.0 (68020 code,
dos.library only, so it runs on any AmigaOS 3 Amiga).

It can be used from a Shell as well:

  Tools/SHA256 FILE                    prints the file's SHA-256
  Tools/SHA256 FILE EXPECT=<sha256>    OK (0) or FAILED (10)
  Tools/SHA256 CHECK=<list>            checks a sha256sum list
