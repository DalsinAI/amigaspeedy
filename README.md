# Speedy the Rollerskater for AmigaOS 3

Reproducible content-port tooling for running **Speedy the Rollerskater** with
the shared [Amiga OpenSurge](https://github.com/DalsinAI/amigaopensurge)
engine. This repository deliberately does not fork OpenSurge, Allegro, SDL, or
OpenGPU.

## Upstream

- Showcase and download: <https://sonicfangameshq.com/forums/showcase/speedy-the-rollerskater.977/>
- Expected archive SHA-256: `e63bb212793305edef648314ea2ff4686cd249fda33787f045b5b475ecde0673`
- Expected extracted directory: `Speedy the RollerSkater Full Version`
- Original engine: OpenSurge 0.5.2.1 / Allegro 5.2.7

The upstream author explicitly describes the game as free and open source and
asks users to give credit. The original package contains the OpenSurge GPLv3
engine source. Game art, music, names, and trademarks remain attributable to
their respective creators and owners.

## Prepare a port

Install the QPAK-enabled shared Amiga OpenSurge engine at
`DH1:OpenSurgeRC1`, extract the upstream archive, then run:

```sh
./scripts/prepare-amiga-port.sh \
  "/path/to/Speedy the RollerSkater Full Version" \
  ./dist/Speedy
```

The script copies only platform-neutral game content, excludes Windows runtime
files, adds the missing modern metadata, and writes an AmigaDOS `StartGame`
launcher. The launcher calls the shared engine with `--game`, enabling
OpenSurge's built-in 0.5.x compatibility pack. Run it with
`Execute DH1:Speedy/StartGame`.

## Standalone release (engine included)
`Speedy-AmigaOS3-standalone-rc1.lha` is the whole game for AmigaOS 3: the
Speedy drawer with the Amiga OpenSurge engine inside it, Speedy's game data
(`game.zip`), GlowIcons, `Install-Speedy` (an AmigaOS Installer script that
copies the drawer where the player chooses), the ReadMe, `CREDITS` and the
licences. No separate engine install is needed: `StartGame` runs
`Speedy/Engine/opensurge` from the drawer it is in.

The engine inside is [DalsinAI/amigaopensurge](https://github.com/DalsinAI/amigaopensurge)
release `v0.6.1.3-amigaos3-rc3` at commit
[`f07fe8a`](https://github.com/DalsinAI/amigaopensurge/tree/f07fe8aa91f6a14c2c79ba00757b85ac40c693fb)
(GFOpenAmigaGCC 16.2.0-open5 rebuild): asset
`opensurge-0.6.1.3-amigaos3-68040-rc3.tar.gz`, SHA-256
`61b569557e8d83a17ac794d0229d3bf0792cc58d4304c54e3ca1745ceae3f4c8`; `dist/opensurge`
`f2ed2503a012b062fb933df1e97bfccccbdef86809e2214b3f502685280f6511`. `port/engine.env`
pins it and `scripts/package-standalone.sh` refuses any other bytes.

Build the archive (Linux, Python 3; the engine asset is fetched with `gh` when
`-e` is not given):

```sh
./scripts/package-standalone.sh -g "/path/to/Speedy the RollerSkater Full Version" [-e opensurge-0.6.1.3-amigaos3-68040-rc3.tar.gz] ./dist
```
The upstream game folder is needed only for this bundle: it becomes
`game.zip` through `scripts/prepare-amiga-port.sh`. Files are stamped with the
commit time and written in a fixed order, so the same inputs give the same
archive bytes. Speedy's credits and terms are in [CREDITS](CREDITS).

`port/` holds what goes in the drawer: `StartGame`, `Install-Speedy` and
`icons/*.info` are generated by `tools/make_installer.py` from
`port/installer.json` and `port/icons/icons.json` with a checkout of
DalsinAI/amicradle (`scripts/port_installer.py`, `scripts/port_icons.py`), and
committed. `tools/lha_archive.py` is AmiCradle's LhA writer.

### The shared-engine route

The earlier route still works: `scripts/prepare-amiga-port.sh` makes `game.zip`
and a `StartGame` (`port/StartGame.shared`) for a shared engine installed at
`DH1:OpenSurgeRC1`. The standalone archive replaces it for players.
